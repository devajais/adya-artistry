# Assets Directory

This directory contains all images and media files for the Adya Artistry website.

## Structure

```
assets/
├── categories/     # Category collection images
├── about/          # About page images
└── README.md       # This file
```

## Adding Images

### Category Images

Place category images in `categories/` folder with these filenames:

- `cards.jpg` - Handmade Cards
- `flowers.jpg` - Paper Flowers
- `supplies.jpg` - Art Supplies
- `crochet.jpg` - Crochet Items
- `custom.jpg` - Custom Orders
- `paper-packs.jpg` - Paper Packs

**Recommended dimensions:** 400x500px (4:5 aspect ratio)

### About Page Images

Place about page images in `about/` folder:

- `hero.jpg` - Main about page hero image
- `workspace.jpg` - Workspace/studio image

**Recommended dimensions:** 1200x800px minimum

## Image Guidelines

- Use high-quality JPG or PNG format
- Optimize images for web (compress while maintaining quality)
- Use descriptive filenames
- Recommended tools: TinyPNG, ImageOptim, or Squoosh
